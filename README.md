# 收银系统 / 会员管家（MemberManager）

[![Build](https://github.com/NoctSis/MemberManager/actions/workflows/ci.yml/badge.svg)](https://github.com/NoctSis/MemberManager/actions/workflows/ci.yml)

面向中小门店（美容美发、养生馆、足浴、小型零售等）的 **Windows 单机会员管理与收银软件**。

会员储值、次卡、开单收银、挂单、员工提成、交接班日结、积分商城、报表导出，一套搞定。
**全部数据存在本机，不联网、不上传、不需要服务器、不需要注册账号。**

- 技术栈：C# 7.3 / .NET Framework 4.8（x86）+ WinForms/WebView2 + React 18 + SQLite
- 支持系统：Windows 10 / 11（64 位系统装 32 位程序，正常使用）；Windows 7 SP1 需用专门的离线包（见 [Windows7使用说明.md](Windows7使用说明.md)）
- 许可证：[Apache-2.0](LICENSE)

> 本项目以源码形式开源。第三方组件与许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)，安全说明见 [SECURITY.md](SECURITY.md)。

> 免安装版没有卸载程序，删除文件夹即卸载（数据在文件夹里，先备份）。

## 二、安装与首次启动

### 2.1 安装

1. 解压 zip，得到一个安装程序 exe。
2. 双击运行。**不需要管理员权限**（装到当前用户目录，不弹 UAC）。
3. 默认安装位置：`C:\Users\<你的用户名>\AppData\Local\MemberManager`
4. 装完勾选「立即启动」即可。

> 安装程序没有代码签名，Windows 可能弹「已保护你的电脑」或 SmartScreen 蓝色提示。
> 点 **更多信息 → 仍要运行** 即可。这是未购买签名证书的常见现象，不代表文件有问题。

### 2.2 第一次登录

| 账号 | 密码 | 角色 |
| --- | --- | --- |
| 店长 | 123456 | 店长（全部权限） |
| 收银 | 123456 | 收银员 |

**登录后第一件事：改密码。** 右上角账号菜单 → 修改密码。默认密码是公开的，不改等于没锁门。

### 2.3 开店前建议按顺序做这五件事

1. **系统设置**：填店铺名称、店号、联系电话（会打印在小票上）。
2. **项目列表**：录服务项目和价格（剪发、洗浴、护理……），商品也可以建在这里。
3. **员工管理**：建员工账号，选角色（店长 / 收银员 / 技师），设登录名和密码。
4. **会员管理 / 会员资产**：建充值方案（充 1000 送 200）、次卡模板（10 次卡 800 元）。
5. **数据备份 → 备份加密**：设一个备份密码。备份文件里有全部会员手机号和余额，加密后拷走也打不开。

## 三、功能说明

左侧导航从上到下：主工作台、收银开单、项目列表、消费记录、会员管理、会员资产、积分商城、员工管理、报表中心、权限与日志、数据备份、系统设置。

### 3.1 收银开单

- 选会员（可不选，散客也能开单）→ 加项目/商品 → 会员抵扣或次卡核销 → 选支付方式（现金 / 微信 / 支付宝 / 余额）→ 结账。
- **挂单**：单子没做完先挂起，点挂单列表里的卡片即可取回继续。挂单不计入当日营收。
- **清空 = 彻底作废**：已经取回来又不想要了，点「清空」会把这张挂单作废（订单行保留、可追溯，但不参与任何统计与营收）。
- **收银台右上角三个按钮**：新会员建档 / 会员充值 / 售卡。只要能进收银台，就一定可以充值和卖卡，不受其他权限开关影响。
- 找零：会员余额超过应收时，多出的部分不扣，按实收扣减。

### 3.2 会员

- 建卡、等级与折扣、余额、积分、标签、生日提醒。
- **会员不做物理删除**：只能「注销 + 余额核销」。注销后号码不释放、历史记录全留，这是为了账能对得上。

### 3.3 储值与次卡

- 充值方案（充多少送多少）、次卡模板（次数/金额/有效期）、售卡、核销、冻结解冻。
- 次卡核销的提成按**该次项目单价**算，不是「卡总价 ÷ 次数」的均价（这样技师做贵项目不会吃亏，也不会超发提成）。

### 3.4 提成与日结

- 提成按员工、按项目/卡核销计算，先「对账」再「结算」，同一批不会重复结算。
- **业绩 ≠ 营收**：营收是实收金额；业绩按项目原价（含次卡抵扣部分）计算。两者差额等于本期次卡抵扣金额，报表上两个口径并列显示。

### 3.5 权限

- 三种角色：店长、收银员、技师。
- 店长恒有全部权限；其他角色按「按人授权」的勾选为准，没配过就按角色默认。
- 默认：收银员 = 会员管理、收银开单、交接班日结、积分商城、储值与次卡；技师默认不给登录权限。
- 敏感操作在**后端**还会再校验一次，绕过界面直接调接口同样会被拒绝。

### 3.6 数据备份（重要）

| 项 | 说明 |
| --- | --- |
| 自动备份 | 可设每天几点备份一次，一天只做一次；当天错过会在下次进备份页时补做 |
| 手动备份 | 随时点「立即手动备份」 |
| 恢复前快照 | 每次恢复前自动给当前数据存一份，恢复错了还能退回来 |
| 轮转清理 | 自动备份留最近 30 个 + 月初 2 个；手动留最近 30 个；快照留最近 10 个 |
| 备份加密 | 开启后备份落地即为密文（`.dbk`，AES-256 + HMAC），恢复时要输密码 |

**备份加密必须记住密码**：程序不保存密码原文，也没有万能钥匙，忘记密码那些备份就永久打不开。
密码至少 8 位，不能是纯数字或常见弱口令（6 位纯数字在离线爆破面前等于没加密）。
密码提示是明文显示在恢复窗口里的，提示别写密码本身。
改密码不会重新加密历史备份——旧的 `.dbk` 仍然要用旧密码恢复。

> 源码公开**不会**让加密变弱：AES-256 + PBKDF2（30 万次）+ HMAC 都是公开标准，7-Zip、BitLocker 用的是同一套，
> 安全性只取决于你的密码有多强。细节见 [SECURITY.md](SECURITY.md)。

**备份文件在哪**：程序目录下 `backups\`。备份是整库快照，**含全部会员资料**，加密关闭时是明文 SQLite，别随手发微信或放网盘。

### 3.7 导出

- 报表可导出 Excel，文件落在程序目录 `exports\`（不让报表散落在桌面）。
- 「导出数据」按表勾选导出 `.db`；「导出选中」把已有的备份文件原样复制出去（换机、存档、给会计）。
- 注意：这些导出文件是**明文**，发给别人前想清楚里面有没有客户手机号。

## 四、数据在哪、怎么换电脑

| 内容 | 位置 |
| --- | --- |
| 数据库 | `<程序目录>\data\member.db` |
| 备份 | `<程序目录>\backups\` |
| 导出文件 | `<程序目录>\exports\` |
| 日志 | `<程序目录>\logs\` |

程序目录默认是 `C:\Users\<用户名>\AppData\Local\MemberManager`。

**换电脑 / 重装系统**：
1. 老机器上「立即手动备份」，把 `backups\` 里最新的那个文件拷到 U 盘（加密的就连密码一起记住）。
2. 新机器装好软件，先启动一次，关闭。
3. 打开「数据备份 → 导入备份」，选 U 盘里的文件，确认导入。
4. 导入完成后重启软件。

> 不要直接用文件覆盖新机器上的 `data\member.db`（新旧版本表结构可能不同）；走「导入备份」，增量列会自动补齐。

**卸载**：控制面板卸载或开始菜单卸载。会问你要不要连数据一起删：
- 选「保留数据」：只删程序，`data\backups\logs\exports` 全部留下，重装后数据还在。
- 选「删除数据」：连 `data\backups\logs` 一起删。
- **`exports\` 里你自己导出的 Excel 永远不会被卸载程序删除**——那是你的文件，不是软件的运行数据。

## 六、从源码构建

### 6.1 环境要求

- Windows 10/11（编译可以在 Win10 上完成，产物照样能在 Win7 跑）
- .NET Framework 4.8 运行时（编译不需要 Visual Studio，仓库自带 Roslyn 编译器）
- Node.js 18+（只编译前端时需要）
- Windows PowerShell 5.1

### 6.2 三步构建

```bat
:: 1) 前端
cd web
npm install
npm run build

:: 2) 后端 + 汇总到 beta\
cd ..
build.bat

:: 3) 运行
beta\MemberManager.exe
```

`build.bat` 调用 `tools\compile-inprocess.ps1`，在 PowerShell 进程内加载 `tools\roslyn\` 的 Roslyn 程序集编译 5 个项目（不启动 MSBuild/csc.exe），把程序集、依赖 DLL、`web\dist`、清单和图标统一整理进 `beta\`。

> 首次克隆必须先构建前端，否则程序起来是空白页（脚本会提示 `WARN web\dist not found`）。

### 6.3 打安装包（可选）

先装 [Inno Setup 6](https://jrsoftware.org/isdl.php)：

```bat
:: 轻量包（不内嵌运行时，约 3MB）
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" /DLIGHT=1 tools\_inno\setup.iss

:: 完整包（内嵌 WebView2 109 + .NET 4.8，约 284MB）
:: 需要先自己准备 deps\wv2-runtime-109\ 和 deps\NDP48-x86-x64-AllOS-ENU.exe（不随仓库分发）
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" tools\_inno\setup.iss
```

`python tools\_pack_release.py` 会把安装包和免安装版整理成对应的 zip。

### 6.4 测试

```bat
%windir%\SysWOW64\WindowsPowerShell\v1.0\powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\_smoke_runner.ps1
```

30 个脚本、400+ 条断言，覆盖建库升级、余额恒等式、退款红冲、提成计算、挂单作废、权限拦截、备份加密、单实例等。
必须用 **32 位** PowerShell（要加载 x86 程序集）。

GitHub Actions 在每次 push / PR 上会走一遍：前端类型检查 → 前端构建 → `build.bat` 编译后端，
产物 `beta\` 作为 artifact 挂在 [运行记录](https://github.com/NoctSis/MemberManager/actions/workflows/ci.yml) 里，
不想本地配环境时可以直接下载一份编译结果。冒烟测试依赖本机数据库，不在 CI 里跑。

## 七、常见问题

**Q：双击没反应 / 一闪就没了？**
A：多半是已有一个实例在运行（程序限制只能开一个窗口，重复打开会直接把已有窗口调到前台）。看任务栏，或到任务管理器确认没有 `MemberManager` 进程。

**Q：界面空白 / 一直转圈？**
A：缺 WebView2 运行时。Win10/11 装 Edge 即可；Win7 见 [Windows7使用说明.md](Windows7使用说明.md)。

**Q：提示缺 .NET Framework 4.8？**
A：装「Win7离线版」安装包，它自带 .NET；或到微软官网下 .NET Framework 4.8 运行时装上。

**Q：换电脑后登录不了 / 会员列表打不开？**
A：数据要从「导入备份」走一遍，别直接拷 `member.db` 覆盖。

**Q：忘记备份密码了怎么办？**
A：没有后门。那些 `.dbk` 备份无法再解开。**但当前正在用的数据库不受影响**，重新设一个密码，之后的新备份用新密码即可。老的加密备份只能删掉。

**Q：能不能多台电脑一起用 / 手机点单？**
A：这一版是单机版。局域网多端方案在设计里（主机唯一写入，不把数据库放共享盘），尚未实现。

**Q：为什么不用 .NET 8 / Electron 这些新技术？**
A：门店电脑普遍老旧，Win7 是真实存在的硬需求；单机离线部署要求零运行时依赖。选 .NET Framework 4.8 + WebView2 是在「够现代」和「装得上」之间的取舍。

## 八、已知限制

- **仅 Windows**：WinForms + WebView2 外壳，不支持 macOS / Linux。
- **仅 x86**：SQLite 原生互操作库是 32 位，64 位系统上以 32 位进程运行，够用但不吃满大内存。
- **单机单实例**：同一数据目录只允许开一个窗口；不支持多台电脑同时连一个库。
- **无自动更新**：升级需手动装新版，数据会自动迁移；装新版前建议先手动备份。
- **无代码签名**：首次运行会有 SmartScreen 提示。
- **无单元测试工程**：回归靠 `tools\` 下的 PowerShell 冒烟脚本（400+ 断言）。
- **备份默认明文**：只有开启「备份加密」后才是密文，请务必设置密码。
- **WebView2 在 Win7 上不再更新**：只能用 109.0.1518.140 及更早版本，这是微软停止支持导致的，无法绕过。

## 九、目录结构

```
src/                     C# 五个项目
  MemberManager.Shell    WinForms 外壳、WebView2、桥接分发、单实例守卫
  MemberManager.BLL      业务服务（收银/会员/提成/报表/权限/备份加密）

  MemberManager.Models   DTO
  MemberManager.Common   路径解析、运行形态识别等公共件
web/                     React 前端（src 源码，dist 构建产物）
lib/ libs/               编译依赖的第三方 DLL（SQLite、Json.NET、WebView2 SDK）
assets/                  应用与安装包图标
tools/                   构建、打包、冒烟脚本；tools/roslyn 为内置编译器
  _inno/setup.iss        Inno Setup 安装脚本
```

## 十、参与贡献

欢迎 Issue 与 Pull Request。提交前请读 [CONTRIBUTING.md](CONTRIBUTING.md)，至少做到：

1. 跑一遍 `tools\_smoke_runner.ps1`，必须 0 FAIL
2. 前端改动跑 `npx tsc --noEmit`
3. 数据库结构只做**增量**变更（`ALTER TABLE` / `CREATE TABLE IF NOT EXISTS`），不改已有 DDL，老库必须能平滑升级
4. 涉及金额的逻辑保持恒等式：`余额 = 充值 + 赠送 − 消费 − 退款 ± 调整`

安全问题请按 [SECURITY.md](SECURITY.md) 私下反馈，不要开公开 Issue。
